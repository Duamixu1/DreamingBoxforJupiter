# 幻境版 · 画面升级方案

真机反馈（2026-10-02）有三条：明信片太花；火车和布景的 3D 效果不错；站与站之间衔接生硬、整体太普通。这一版的目标是：**一条连续的幻境旅程，少而精的灵兽，优雅而不夸张。**

## 1. 衔接：让五站连成一个世界

| 问题 | 做法 |
| --- | --- |
| 沙地、雪地是按站贴的方块，交界处一条硬边 | 新增**连续地形**：一整条地面，顶点色按地貌渐变，过渡节奏和天色一致 |
| 远景每站各摆几座锥形山，换站时突然换一批 | 新增**三层远山**，横贯全程，像水墨画那样越远越淡。山野段高耸带雪，海边段压低成海上远岛 |
| 换站只靠几棵树 | 两站之间加一道**云海**。火车「穿云」进入下一处风景，正好遮住地貌交界 |
| 天空板贴得太近，远景没有层次 | 天空退到远山之后，太阳加一圈光晕，夜空星星铺满 |

## 2. 幻境元素（灵感：《山海经》与希腊神话）

| 元素 | 出处与寓意 | 出现位置 | 在 3D 里的作用 |
| --- | --- | --- | --- |
| **青鸟** | 西王母的信使，"青鸟殷勤为探看" | 全程伴着火车飞，终点衔来那封信 | 中景，贯穿全程，把结尾的信和旅程连起来 |
| **鲲** | 北冥有鱼，其名为鲲 | 海边黄昏，在云中与火车同向缓游 | 远景大体量，视觉冲击最强的一幕 |
| **独角白鹿** | 白鹿是祥瑞，独角兽取自希腊传说 | 山野站，立在岩台上，角有微光 | 中景，静中有动，等火车经过 |
| **浮空仙山** | 蓬莱、昆仑一类的仙山 | 全程天空，倒悬岩岛、松、小亭、瀑布 | 远中景之间，补足天空层次 |
| **天灯** | 夜城祈愿 | 夜晚的城市，一盏盏升起 | 前后都有，纵深感最强 |

风格约束：灵兽只用修长的线条和柔和的配色（青、金、月白），不做张牙舞爪的造型。数量少，一站一个主角。所有动作都只读世界时间，停摇时一起静止。

## 3. 精细度

- **这一版（程序化）**：先把构图、节奏、衔接做对。灵兽是程序化占位，远看成立，近看还比较朴素。
- **下一版（Tripo）**：给灵兽和仙山各开一个模型槽位，用 Tripo 生成精模替换。提示词见 [Tripo模型清单.md](Tripo模型清单.md) 末尾的「幻境版待接入」。替换时保留程序化的动作，比如翅膀扇动和鲲的游动。

## 4. 性能预算

新增的绘制约十几次：地形、远山、仙山、瀑布、云海、鲲、青鸟、白鹿、天灯。大约增加 1.5 万三角面。9 视点在 RK3566 上能不能跑满帧率，需要真机确认；卡的话，先把云海粒子和天灯数量减半。

## 5. 开关

- 明信片：`config.js` → `SCENE.postcards`，目前为 `false`。
