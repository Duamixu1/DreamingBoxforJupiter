# A · 西方玄幻 · 原画元素拆分

把穆夏《一日四时》四幅原画拆成一层层，目标是在 Jupiter 上做出多层次的立体效果，原画元素只作参考，不要求一比一还原。数据在 [prototype/src/mucha-layers.js](../../prototype/src/mucha-layers.js)，布景工作台的「三版对照」页签直接读它（`http://localhost:5174/studio` → 三版对照）。

原图在 [refs/mucha/](refs/mucha/)：`scan-*.jpg` 是公有领域扫描版（约 740×2000），`photo-*.jpg` 是展览实拍高清版（约 2200×5900，CC BY-SA 4.0，公开使用要署名维基共享资源上的拍摄者 Tylwyth Eldar）。

## 和 Jupiter 屏幕的协调

| | 原画 | Jupiter 屏幕 |
| --- | --- | --- |
| 宽高比 | 约 0.37（细长竖条，去掉底部标题字后） | 0.625（10:16） |
| 尺寸 | — | 可视区 135.4 × 216.6 mm，1200 × 1920 px；连木框 164 × 262 mm |

两种放法（工作台里可以切换对比）：

- **等高（完整）**：整幅画占满屏幕高度，显示为约 81 × 217 mm，左右各留约 27 mm，正好留给窗墙和相邻窗的边。扫描版 2000 px 高，在 1920 px 的屏幕上约 1:1，不会糊。**推荐**：穆夏的装饰框是风格的核心，整幅保留。
- **铺满（裁切）**：宽度占满屏幕，只能看到原画中间约 60% 的高度（以人物为中心），上下装饰框被裁掉；扫描版要放大约 1.6 倍，偏软，要用实拍高清版。

最下面的标题字（ÉVEIL DU MATIN 等，画面 95% 以下）一律不要：细小文字在透镜屏上会串扰。

## 深度层

焦平面（深度 0）= 人物所在的深度，盒子里这一层最清楚。正数朝观众，负数往里。

| 颜色 | 深度 | 放什么 |
| --- | --- | --- |
| 蓝 | −7 左右 | 背景：天空、远景 |
| 绿 | −4 到 −1 | 中后景：树、芦苇、飘带、岩石 |
| 金 | 0 | 人物 |
| 橙 | +1 到 +2 | 压在人物身前的前景：长纱、雏菊、草茎 |
| 红 | +3 左右 | 外框，全片最近的一层 |

## 怎么用：精修工作台

`http://localhost:5174/studio` → 顶部「精修工作台」。左上选窗（晨 / 昼 / 暮 / 夜），再选三步：

1. **① 原图排版**：原画放在 Jupiter 屏幕框里（真实比例 + 木框）。预设「等高完整 / 铺满裁切」，或在屏幕上拖动移动、滚轮缩放（自动切到「自定义」）；两侧可选窗墙色 / 黑 / 模糊延展；右侧实时算出画作的毫米尺寸、留边、原图放大倍数。底部是四扇窗的排版缩略，「四扇窗都用这个排版」一键统一。
2. **② 元素拆分画布**：在原画上画、改元素。工具栏「画新元素」逐点单击、回车收口；选中后拖顶点改形、双击边加点、Alt+点顶点删点、拖内部整体移动；右侧改名字、深度、做法、备注。底部陈列所有精修元素的抠图（按深度从远到近），每个可以「导出 PNG」或「生成 3D」（直接送 Tripo，结果存为 `el_<窗>_<元素>.glb`；人物送到对应的 `mucha_lady_*` 槽位）。
3. **③ 3D 预览**：元素按深度摆成贴片，已经有 3D 模型的元素自动换成模型；「立体摇摆」模拟在裸眼屏前左右看，「侧看分层」可以拖动旋转看各层拉开多少；也能切到「盒子里的 3D 布景」。

所有改动自动保存到 `prototype/assets/layers/<窗>.json`，刷新不丢；第一次打开时用上面表格里的默认拆分。

**原图对齐**：实拍高清版带了实物画框，和扫描版位置不同。已经自动对齐（`mucha-layers.js` 的 `photoRect`），所以在任一版本上画的区域，换到另一版本也对得上；夜那幅底部仍有轻微透视偏差。导出 PNG / 生成 3D 时用当前选的原图，建议排版里选「实拍高清」再导出，细节更多。
