# 《晨之苏醒》元素提取

来源：`refs/mucha/photo-1-dawn.jpg`（实拍高清，CC BY-SA 4.0，拍摄者 Tylwyth Eldar），按扫描版坐标对齐后提取。全部用代码完成（OpenCV 分水岭抠图 + 按方向补色 + 对称镜像 + 重绘），没有用 Tripo 额度，也没有用 AI 生成图。

每个元素：

| 文件 | 用途 |
| --- | --- |
| `*_front.png` | 正面，透明底 |
| `*_front_white.png` | 正面，白底 —— **给 Tripo 单图生成用这张** |
| `*_back.png` / `*_back_white.png` | 空白背面：同一轮廓左右镜像，平涂主色 |
| `*_sheet.png` | 正反并排，检查用；Tripo 多视图生成可分别上传 front / back |
| `*_front_full.png` | 原分辨率中间图（不进仓库） |

| 元素 | 怎么补的 |
| --- | --- |
| `woman` 晨之女（头、身体、双手、整条拖摆） | 沿墨线抠出；压在裙子上的两片蓝绿长叶、两根细草茎、右侧衣摆上的橙黄斜叶，按叶子两侧的衣料颜色逐列补上；小臂穿过的那段窗框竖条按两侧颜色补上。右侧被窗框压住的衣摆截在窗框内沿 |
| `frame` 窗框（含上角百合、底部翼饰、两侧小窗） | 中间拱窗和两侧小窗镂空；她左手压住的那段左柱用右柱镜像补齐；底部标题字去掉 |
| `trees` 背后的四根细树干 | 原画里顶部被拱框裁掉、底部被肩膀和草丛挡住，按测量的中线和宽度重绘成完整的树干（平涂 + 高光 + 墨线，颜色取自原画树干） |
| `tree_crown` 头后那棵带树冠的树 | 树冠按原画抠出；被头发挡住的树干按原画位置往下接到地面 |

已知问题：补色处细看是平滑过渡，没有原画的衣褶线；晨之女左臂外侧边缘还残留少量背景绿色。
