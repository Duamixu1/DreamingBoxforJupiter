# A · 西方玄幻 · 分站拆解（一日四时）

故事与出处见 [story.md](story.md)，风格见 [style.md](style.md)。

## 总览

常速（1 圈/秒）每站约 18 秒，4 站共约 72 秒，之后继续摇展开信。

| # | 画 | 时辰 | 季节 | 女子在做什么 | 猫在做什么 | 身后的圆 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 晨之苏醒 | 清晨 | 春 | 醒来，舒展双臂 | 醒来，伸懒腰，叼信，跳上长发 | 初升的淡日 |
| 2 | 昼之光辉 | 正午 | 夏 | 转脸迎向太阳，衣摆被风吹起 | 沿长发走，从她手臂下穿过 | 正午的白日 |
| 3 | 暮之沉思 | 黄昏 | 秋 | 坐着出神，接住一片落叶 | 在她身边坐下，一起看落日 | 下沉的红日 |
| 4 | 夜之安眠 | 夜晚 | 冬 | 躺在雪云里睡着，缓慢呼吸 | 放下信，蜷起来睡了 | 满月 |

**身后的圆就是太阳和月亮**。四站连起来看，圆从低到高再落下，最后换成月亮：这个大圆既是穆夏式的光环，也是一天里天体的轨迹。

## 怎么从一幅画走到下一幅

四幅画**左右并排**，像一组四联窗。镜头沿着长发向右平移，从一扇窗移到下一扇。

- **路**：女子的长发从她头上飘起，越出画框，在两扇窗之间的空中划过一道弧，接到下一位女子身边。猫就走在这条发丝上。
- **转场**：两扇窗之间那根**窗柱**是前景，镜头平移时它从画面前方扫过，正好把上一季遮掉、把下一季露出来。前景扫过镜头是裸眼 3D 视差最强的时刻，比淡入淡出更出效果。
- **云门**（可选）：窗柱后面加一层薄云，对应《伊利亚特》里时辰女神开合云门的说法。云用柔边粒子，不用低多边形（真机上低多边形的云近看像石块）。
- **发色**：长发的颜色随季节渐变，春天是浅金，夏天是赭金，秋天是赤褐，冬天是银灰，落在夜里时变成深靛色。

## 竖屏 10:16 的分层

四站共用一套分层，内容随季节换：

| 层 | 深度 | 内容 |
| --- | --- | --- |
| 前景 1 | 最近 | **窗框**：简化的哥特尖拱，象牙金色，只有大轮廓、没有雕花；两侧的窗柱 |
| 前景 2 | 近 | 窗台上的花或雪、上沿垂下的枝条；飘落的花瓣、叶子、雪（柔边粒子） |
| 中景 | **焦平面** | 女子、长发、**黑猫和信** |
| 后景 | 中远 | 身后的圆（日 / 月），以及季节树木 |
| 远景 | 最远 | 季节风景和天空，越远越淡 |

女子全身约占画面高度的 65–70%，参照穆夏海报里人物顶天立地的比例。

## 动态的总规则

- **一切只读 worldTime**。停摇时，女子停在伸懒腰的半途，叶子停在半空，猫停在半步。这正是"停下的是故事"。
- **动作要慢、要大**：每个动作至少持续 3 秒世界时间，幅度要大到真机上看得出来。抖动、快速的小动作在 9 视点下只会显得糊。
- **每站一个主动作**：女子一个，猫一个，再加一个背景里的小生灵，不要更多。
- 下文的"站内进度"指这一站的 0 → 1。

## 第 1 站 · 晨之苏醒（清晨 · 春）

| 项目 | 内容 |
| --- | --- |
| 时间 / 天气 | 日出前后，湖面薄雾，空气清凉 |
| 情绪 | 刚醒，慵懒，柔软 |
| 主色 | 嫩绿、杏花粉、象牙白、淡金 |

| 层 | 内容 |
| --- | --- |
| 前景 | 尖拱窗框；窗台下是一丛丛春花（大花头：鸢尾、水仙、杏花）；上沿垂下杏花枝 |
| 中景 | 女子站着，刚醒，身披浅色长袍；黑猫蜷睡在她脚边，爪子下压着信 |
| 后景 | 身后一轮刚升起的淡日（大圆，边缘柔光）；开花的果树 |
| 远景 | 晨雾里的湖，远山浅淡 |

**女子的动态**

| 站内进度 | 动作 | 做法 |
| --- | --- | --- |
| 0 – 0.15 | 低头闭眼，双手交叠在胸前，长发垂着 | 静止起始姿态 |
| 0.15 – 0.6 | **慢慢抬头，双臂向上舒展**，在头顶交握；长发被晨风吹起、扬向右侧，变成猫的路 | 骨骼动画，时间轴接 worldTime；长发是程序化飘带，摆幅随进度增大 |
| 0.6 – 1 | 保持舒展，衣摆轻摆 | 衣摆用顶点位移，按高度加权 |

**猫的动态**：0 – 0.2 蜷睡，耳朵抖一下；0.2 – 0.4 起身伸懒腰（前身压低、后腿蹬直），和女子的舒展同步，像在学她；0.4 – 0.55 低头叼起信；0.55 – 0.7 一跃跳上扬起的长发；0.7 – 1 沿长发向右走出窗框。

**背景小生灵**：湖上一对天鹅，缓缓滑过（剪影，2 只）。

**和下一站衔接**：猫沿长发走出第一扇窗，窗柱从前景扫过；雾散开，光线从淡金变成正午的白亮。

## 第 2 站 · 昼之光辉（正午 · 夏）

| 项目 | 内容 |
| --- | --- |
| 时间 / 天气 | 正午，晴，有热风 |
| 情绪 | 明亮，舒展，热烈 |
| 主色 | 赭金、麦黄、鼠尾草绿、天青 |

| 层 | 内容 |
| --- | --- |
| 前景 | 尖拱窗框；窗台下是罂粟和矢车菊（色块分明，红色只用小面积）；上沿垂下浓绿的枝叶 |
| 中景 | 女子站着，一只手臂高举，扶着头顶的树枝；长发从左边接进来，绕过她的肩，再向右飘出 |
| 后景 | 身后正午的白日（大圆，最亮）；一棵枝叶茂密的大树 |
| 远景 | 金黄的麦田起伏到天边，热空气里远处微微发虚 |

**女子的动态**

| 站内进度 | 动作 | 做法 |
| --- | --- | --- |
| 0 – 0.3 | 侧身，脸朝左下 | 起始姿态 |
| 0.3 – 0.7 | **慢慢转过脸、仰头迎向太阳**，高举的手臂随之舒开 | 骨骼动画 |
| 全程 | 衣摆和长发被热风吹动，幅度是四站里最大的 | 顶点位移 + 程序化飘带 |
| 全程 | 树叶间漏下的大块柔光斑在她身上缓缓移动 | 一层投影光斑贴图，随 worldTime 平移 |

**猫的动态**：全程沿长发小跑，0.45 – 0.6 从她高举的手臂下方穿过（这是这一站的视觉焦点：黑猫穿过一片金色）。

**背景小生灵**：麦田上空三两只蝴蝶，大翅膀，慢速扇动。

**和下一站衔接**：窗柱扫过；麦田的金色渐渐转成枫叶的赤褐，太阳开始往下落。

## 第 3 站 · 暮之沉思（黄昏 · 秋）

| 项目 | 内容 |
| --- | --- |
| 时间 / 天气 | 日落时分，无风，落叶自己掉落 |
| 情绪 | 安静，出神，带一点怀念 |
| 主色 | 琥珀、赤褐、梅紫、暗金 |

| 层 | 内容 |
| --- | --- |
| 前景 | 尖拱窗框；窗台上铺着落叶；上沿垂下几枝红叶 |
| 中景 | 女子坐在石栏上，侧身，手托着脸，望向落日；长发垂落，在她身边铺成一段平缓的路 |
| 后景 | 身后一轮下沉的红日（大圆，最暖）；秋林 |
| 远景 | 远处的湖面映着晚霞，天空从琥珀过渡到梅紫 |

**女子的动态**

| 站内进度 | 动作 | 做法 |
| --- | --- | --- |
| 全程 | 头极慢地向一侧倾，像在出神 | 骨骼动画，幅度小但持续 |
| 0.2 – 0.5 | **空着的那只手慢慢摊开、掌心向上**；一片叶子沿螺旋落下，正好落进她掌心 | 叶子沿预设曲线下落，落点和手掌时间对齐 |
| 0.5 – 1 | 握着叶子，继续望着远处 | 静止 |

**猫的动态**：0 – 0.4 沿长发走来；0.4 – 0.65 **在她身边坐下**，尾巴卷起来，和她朝同一个方向看落日（全片唯一一段两人一起停下的时刻）；0.65 – 1 起身，接着往前走。

**背景小生灵**：一行大雁排成人字，从远景天空缓缓飞过。

**背景变化**：太阳随站内进度下沉，颜色逐渐变红；落叶粒子持续缓慢飘落。

**和下一站衔接**：窗柱扫过；落叶在空中变成雪花，天色转为深蓝。

## 第 4 站 · 夜之安眠（夜晚 · 冬）· 终点

| 项目 | 内容 |
| --- | --- |
| 时间 / 天气 | 深夜，静静下雪，月亮很亮 |
| 情绪 | 安睡，温柔，安心 |
| 主色 | 深靛、银灰、雪白、月光淡金 |

| 层 | 内容 |
| --- | --- |
| 前景 | 尖拱窗框，窗台积雪；雪花飘落（柔边粒子，越近越大） |
| 中景 | 女子侧卧在一团雪云上睡着，长发铺开、流进夜空，像一条深色的河；猫和信 |
| 后景 | 身后一轮满月（大圆，银白，最安静）；落满雪的松枝 |
| 远景 | 雪原，地平线很低；夜空里少量大而柔的星（不连线、不写字） |

**女子的动态**

| 站内进度 | 动作 | 做法 |
| --- | --- | --- |
| 全程 | **缓慢呼吸**：胸口和肩膀轻轻起伏，一个周期约 4 秒世界时间 | 骨骼或缩放，幅度约 2–3% |
| 0.7 – 1 | 猫蜷到她身边时，她的手微微移动，搭在猫身旁 | 骨骼动画，幅度很小 |
| 全程 | 长发在夜空中极慢地流动，星星沿发丝明灭 | 程序化飘带，摆幅是四站里最小的 |

**猫的动态**：0 – 0.4 沿长发走下来；0.4 – 0.55 在她身边**放下信**；0.55 – 0.75 原地转一圈；0.75 – 0.9 **蜷起来**，金色眼睛慢慢闭上；之后保持睡姿，随她一起缓慢呼吸。

**背景小生灵**：没有。这一站只留雪和呼吸，越静越好。

**终点 · 信**：猫闭上眼以后继续摇，按共享引擎的流程：信从猫身边升起、开封、抽出信纸、展开。只改三处：

- 封蜡：一枚**新月**图案（大形状）
- 信纸：象牙白底
- 默认文字：

  > 从清晨到深夜，从春天到冬天，
  > 我都在想你。

读完以后画面保持：雪继续下（读的是 worldTime，所以不摇的时候雪也停着），不自动重播。

四位女子的面部都做简洁、几何化的处理，不追求表情细节：真机上看不清，还容易让人觉得诡异。

## 技术上要先确认的事

| 问题 | 为什么重要 | 备选 |
| --- | --- | --- |
| Tripo 生成的人物和猫能不能自动绑骨骼、导出带骨骼的 GLB | 决定人物动画的做法 | 不行就把模型在 Blender 里拆成头、手臂、躯干几块，按枢轴旋转 |
| 骨骼动画能否由 worldTime 驱动 | 停摇必须全部静止 | Three.js 的 `AnimationMixer.setTime()` 可以直接按世界时间定帧，不按真实时间播放 |
| 4 位女子 + 猫的面数 | 每个视点 ≤ 3 万三角面 | 同一时间画面里最多两位女子，按站剔除；每位女子约 6000 面以内，猫约 2000 面以内 |
| 黑白高对比的重影 | 猫和信是全片对比最强的东西 | 猫和长发固定在焦平面上 |

## 原型现状（2026-10-02，分支 `story/western`）

代码在 [prototype/src/mucha.js](../../prototype/src/mucha.js)，内容（站名、信文、每站时长）在 `config.js` 的 `MUCHA`。打开 `http://localhost:5173/` 就是这一版；`?theme=classic` 切回小火车。

**已经做到**

- 四扇尖拱窗左右并排，镜头每站前 80% 停在窗前，后 20% 向右平移；窗墙上一枚大圆章，平移时从镜头前扫过
- 四位女子的动作全部按站内进度和 worldTime 驱动：晨之女抬头举臂、昼之女转脸迎日、暮之女歪头摊掌接叶、夜之女呼吸并挪手；停摇即停在半途
- 长发是程序化飘带：每扇窗一条，从左侧窗墙后进、绕过她的头、从右侧窗墙后出，相邻两条在墙后相接；主发上沿就是猫走的路，另有两缕副发
- 黑猫：睡 → 伸懒腰 → 叼信 → 跳上长发 → 走（经过昼之女头后、手臂下）→ 在暮之女身旁坐下看落日 → 落到雪云上 → 放下信、转一圈、蜷睡；纯黑 + 淡暖色边缘光，始终在焦平面
- 每站一个圆（淡日 / 白日 / 下沉的红日 / 满月）、上沿垂枝、窗台花（春花 / 罂粟矢车菊 / 落叶 / 积雪）、柔边粒子（花瓣 / 光尘 / 落叶 / 雪）、背景小生灵（天鹅 / 蝴蝶 / 大雁）
- 信：从猫身边升起，新月形封蜡，信文按 `MUCHA.letter`

**性能（桌面 Chrome 实测场景统计，未上真机）**：停在一扇窗前每视点约 1.2–1.8 万三角面、60–90 次绘制；平移时两扇窗同时可见，约 2.3 万面、约 100 次绘制。面数在 3 万预算内；绘制次数比火车版（约 25 次）多，真机卡的话先合并女子身上的零件、减少粒子组。

**还是占位的**

- 四位女子是程序化拼的几何体，脸没有五官，夜之女侧卧的轮廓尤其粗糙。按 [refs/prompts.md](refs/prompts.md) 出设定图、用 Tripo 生成并绑骨骼后替换；关节名（spine / neck / 双臂 shoulder · elbow）和动作参数保留
- 黑猫同上，Tripo 精模到位后保留 `pose()` 的参数接口
- 没有新增音效（火车的蒸汽声在这一版已关掉）
